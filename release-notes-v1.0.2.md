# Release Notes: Version 1.0.2 - The "Frosted Glass" Update

**Release Date:** 2025-12-12

We're excited to announce version 1.0.2, which brings a significant visual refresh to the LAB Digital Workshop! This update focuses on modernizing the user interface with a sleek "glassmorphism" effect.

## What's New?

### ✨ UI/UX Refresh: Glassmorphism

We've implemented a "frosted glass" effect for all tool containers. This creates a beautiful, layered appearance that makes the interface feel more modern and dynamic. The subtle transparency and blur help tools stand out against the background, improving focus and visual hierarchy.

### 📝 Updated Styling Guide for Developers

To ensure visual consistency across all parts of the application, especially for our standalone (iframed) tools, we have updated the `styling_guide.md`. The guide now includes the CSS variables and implementation details for applying the new glassmorphism effect, making it easy for contributors to build tools that seamlessly match the new aesthetic.
