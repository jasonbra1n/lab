# Contributing to LAB: Digital Workshop

First off, thank you for considering contributing! This project is designed to be a collaborative and AI-friendly space. Your help is greatly appreciated.

This document provides a high-level overview of the contribution process. For detailed technical information, please refer to the other documentation files.

## Where to Start?

Not sure where to begin? A great place to start is the **[Project Roadmap](ROADMAP.md)**. It lists planned features and tasks that are ready to be worked on.

You can also review the **[Changelog](CHANGELOG.md)** to see what has been recently added or changed.

## The Contribution Workflow

We follow a standard GitHub fork-and-pull-request workflow.

1.  **Fork the Repository**: Click the "Fork" button at the top right of the repository page to create your own copy.

2.  **Clone Your Fork**: Clone your forked repository to your local machine.
    ```bash
    git clone https://github.com/[your-username]/lab.jasonbrain.com.git
    cd lab.jasonbrain.com
    ```

3.  **Create a New Branch**: Create a descriptive branch name for your feature or bugfix.
    ```bash
    git checkout -b feature/my-new-tool
    # or
    git checkout -b fix/bug-in-calculator
    ```

4.  **Make Your Changes**: This is where you'll add your new tool or fix a bug. For detailed instructions on the project's architecture and how to add a new tool, please read our **[Development Guide](DEVELOPMENT_GUIDE.md)**.

    If you are creating a new tool, please also consult the **[Styling Guide](styling_guide.md)** to ensure its appearance is consistent with the rest of the application.

5.  **Commit Your Changes**: Write a clear and concise commit message.
    ```bash
    git commit -m "feat: Add new breathing exercise tool"
    ```

6.  **Push to Your Fork**: Push your changes to your forked repository on GitHub.
    ```bash
    git push origin feature/my-new-tool
    ```

7.  **Submit a Pull Request**: Open a pull request from your branch to the `main` branch of the original repository. Provide a clear description of the changes you've made.

We will review your pull request as soon as possible. Thank you for your contribution!
