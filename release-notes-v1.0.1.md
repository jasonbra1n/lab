# LAB Digital Workshop - Version 1.0.1 Release Notes

**Release Date:** December 12th, 2025

---

Version 1.0.1 is here! This release focuses on improving the developer experience and expanding our "Rest" pillar with a new creative tool.

## Key Highlights

### ✨ New Features

- **Theme Syncing for Standalone Tools:** Standalone tools (loaded in iframes) now automatically sync with the main application's light/dark theme. This creates a more seamless and visually consistent experience when switching between tools.

- **New "Cymascope" Tool:** Explore the intersection of sound and art with the new Cymascope tool, located in the "Rest 🌿" pillar. This sound visualizer generates beautiful cymatic patterns in real-time.

### 🛠️ Improvements

- **Improved Developer Documentation:** The project's core documentation (`README.md`, `ROADMAP.md`, `DEVELOPMENT_GUIDE.md`) has been updated for better accuracy and clarity, making it easier for new contributors to get started.

- **Project Structure Cleanup:** Key documentation files have been moved to the project root for better discoverability, following common open-source conventions.

Thank you for your continued support and contributions!
